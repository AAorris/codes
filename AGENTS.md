# Agents

Single pointed focus is the approach to be used in this repository.

# Process

To begin, perform a reflection as an assistant response.

Visualize the object of focus as an assistant response.

Begin making tool calls to align the current state with the object of focus, with no responses necessary. Complete as much work as possible unless excited or lax. These can be seen as writing too much code not relevant to the object, or repeating some pattern many times.

Complete the necessary work with focus on the object until testing is satisfied.
