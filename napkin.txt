HyperNap - Restful Hypertext typesetting language

HyperNap is an authoring format designed for HTTP servers.

- The core primitive is a request handling function
- A request handler knows about the host, URI, headers, and so on
- Each request is for a resource, or fragment of a resource
- Resources can be protected, and the resource owner can author in authorization details
- Content is written to produce responses in the requested format defined by Accept, ex. html, txt, md, json

Consider some abstract text resource like

```nap
---
slug: /
name: my website
auth: public
---
# greeting
hello world
## motd
today is a day
## now
@[now](/now)
```

Waving our hands, we can imagine making requests against this resource

GET / -Accept json

```json
{
  "main": {
    "greeting": "hello world",
    "motd": "today is a day",
    "now": ...
  }
}
```

GET /index.json#greeting -Accept json
"hello world"

REST conventions, like resource URI and fragments should be native to the authoring format. The format above is simply illustrative, and must be totally redefined below to satisfy other concerns.
